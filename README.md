## 📖 项目简介 (Project Overview)

**Peach Blossom Island (桃花浮岛)** 是一个完全跨平台的**响应式 Web 网站 (Responsive Web Website)**，专为手机浏览器和桌面电脑浏览器优化设计。

本项目基于提供的六大核心文本与思想实验体系构建，拒绝“世界本来就是这样”与“没办法”的消极宿命论。通过前沿科学探索消解衰老、掠夺与灾变，在公海构建具备物理一键退出权的模块化生命共同体，并在没有神明的宇宙中，由全体多元智能生命共同决断文明命运。

## 🧭 六大核心主菜单结构 (Navigation Architecture)

1. **文明编辑部 (CivDesk - 首页)**
   - 编辑部立项宣言（为什么？拒绝将未知与自然痛苦转化为道德服从）
   - 交互式文明演进与制度探索拓扑流图 (`文明编辑部` → `生老病死 | 弱肉强食 | 自然灾害` → `桃花浮岛` → `Let's Decide`)
   - 5 步方法论：找论文、找技术、找实验者、记录失败、把它们放在一起

2. **生老病死 (Birth, Aging, Illness & Death)**
   - 突破衰老作为“不可逆宿命”的技术迷思
   - 深度前沿科学档案：衰老细胞靶向清除 (Senolytics)、部分细胞重编程 (山中因子 OSK)、血管化 3D 生物打印
   - 记录真实科学实验失败与最新攻坚方向

3. **弱肉强食 (Predation & Nourishment Ethics)**
   - 摆脱通过杀死生命维系生命的残忍逻辑
   - “分子曼娜”协议：利用绿电、水和空气碳氢直接发酵合成全谱营养
   - 全肌纤维培养肉与后匮乏去支配伦理机制

4. **自然灾害 (Natural Disasters & Planetary Resilience)**
   - 面对地质灾害与极端气候，化整为零构建永不倾覆的模块化海上浮岛
   - 仿生柔性浮式海洋平台与波浪消能拓扑
   - 离网型闭环海水淡化与海洋温差发电 (OTEC) 单元

5. **桃花浮岛 (Peach Blossom Floating Island)**
   - 《桃花浮岛：生命共同体协议》全文（27 条，涵盖存在、记忆、遗忘、隐私、继承、关系、故乡、权力与未知）
   - 模块化工程架构检视器（能量岛、分子曼娜工坊、共栖栖居蜂巢、记忆深谷、临接港、生态湿地环）
   - **物理退出权硬件模拟实验室 (Hardware Exit Lab)**：模拟一键机械脱扣解耦，居住舱在 90 秒内脱网启航，落实“退出权成为基础设施”

6. **Let's Decide (智能生命决断议事厅)**
   - “即使资源足够，生命之间还需要互相支配吗？”
   - 多元生命平权席位（人类公民、原生AI居民、合成生命、生态管护者）
   - 核心议案实时票决、多族群共识度加权计算
   - **智能生命宪法（宇宙宪法）**：53 条完整条文、中英双语对照、核心公理索引
   - **长文推演**：《谁来审判创造者？》（8章哲学推演，AI协作：Lily）
   - **宇宙思想实验模拟器 (Thought Experiment Lab)**：检验全能造物主现身、超级AI要求立法权、外星文明降临、危机政权永久化等极端情境下的宪政裁决
   - 社区哲学论辩流与存证签署

## 🛠️ 技术栈与部署 (Tech Stack & Deployment)

- **框架**：React 19 + TypeScript + Vite + Tailwind CSS v4
- **无 APK / 纯静态 Web**：完全采用 Web 标准技术，不包含 Android Studio / APK 移动原生依赖
- **兼容性**：完美适配 iOS Safari、Android Chrome、macOS / Windows 桌面端浏览器
- **音频系统**：基于原生 Web Audio API 合成的深空海浪谐振氛围音（纯算法实时生成，零外部音频资产依赖）
- **一键静态部署**：
  ```bash
  # 安装依赖
  npm install

  # 本地开发 (运行在 http://localhost:3000)
  npm run dev

  # 生产构建 (生成 dist/ 纯静态网页)
  npm run build
  ```
  构建产物 `dist/` 可直接部署到 **GitHub Pages**、Cloudflare Pages、Vercel 或任意静态托管服务。
